行動・売上の概況

検証済み集計を読み込んでいます。

PURCHASE REVENUE

日別のpurchase売上

USD / event_date基準

イベント粒度の売上です。user/session欠損も含め、返品・税・送料を推測で差し引きません。3か月比較はすべての月を表示します。

STRICT SESSION FUNNEL

時刻が厳密に進む購入ファネル

同じ匿名user/session内の view_item → add_to_cart → begin_checkout → purchase。同時刻は順序不明。商品をまたぐsession単位で、月は最初の観測event_dateに帰属します。

OBSERVED BUYERS

過去月にも購入した当月購入者

月を選ぶ前に全3か月の購入履歴を参照します。同じ月の複数購入は分子に含めません。11月は比較できる過去月がなく、12・1月も期間前の購入は不明です。

PAGE EXPLORATION

2種類以上のURLを見たsession

page_viewの有効な完全URL文字列だけを数えます。query違いも別URL。URLが観測できないsessionは分母から外し、利用可能率を併記します。

PURCHASE ITEM GRAIN

商品別のpurchase売上・数量

商品名カテゴリ売上 USD数量明細行

purchaseイベントのitemsだけを別粒度で集計。event売上を明細へ複製しません。欠損金額は「未取得」、実測0は0として表示します。元のイベントは重複除去していません。

OBSERVED ATTRIBUTES

記録された属性の内訳

売上の上位10区分と残りの合計。属性の欠損・placeholderは区別します。属性別ユーザーは同じIDが複数区分に現れるため非加算です。接続地域は居住地、初回獲得元はsession流入や広告効果とは限りません。

DATA QUALITY & COVERAGE

数値の前提を確認する

重複候補・重複transactionは診断値です。削除・売上補正はしていません。refundイベント0でも返品なしとは判断できず、返品率や純売上は算出していません。

指標・出典・検証の約束

この画面の定義
どのように検証したか

全31 Parquetのchecksum、全92日の件数・商品要素数・売上を元BigQueryの1,465区分と照合済み。dbtで順序の逆転、同時刻、複合sessionキー、同月再購入、月跨ぎ、NULL/0、欠損IDの売上保持を検査しています。

画面へ配信するのは集計JSONだけです。匿名user/session/transaction ID、完全URL、イベント時刻の明細は配信しません。原票はローカルのParquet viewで参照し、一時GCP環境はcleanup済みです。
